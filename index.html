Why HAGHS

Stays on your hardware

No cloud, no telemetry, no outbound traffic. HAGHS reads kernel pressure, your database size and Home Assistant's own registries directly. Nothing about your home leaves your network.

Nothing hidden

Every threshold and penalty is in the source and in the docs. No surprise weights, no black box. Read the math, argue with it on GitHub, or send a pull request.

Tells you what to fix

Every missing point comes with a plain-language recommendation, in English, German or Brazilian Portuguese. The dashboard cards link to the right settings pages.

// the score

Two pillars.
One number.

The index weights long-term hygiene over short load spikes. Floor rounding keeps a perfect 100 rare: the score is always rounded down.

Score = ⌊ Hardware × 0.4 + Application × 0.6 ⌋

Zombies, open repairs and overdue watched entities cap the application score at 99, so the config audit bonus can never hide them.

Hardware · 40%

  • CPU, RAM and I/O via kernel PSI
  • Sensor fallback without PSI
  • Disk space per storage type
  • Raspberry Pi under-voltage

Application · 60%

  • Zombie entities
  • Updates and Core age
  • Integration health, repairs
  • Database, backups, config audit

Up and scoring
in five minutes.

  1. InstallHome Assistant 2026.11 and later: Settings › Marketplace, search “HAGHS”, Install. Up to 2026.10: download HAGHS in HACS and restart Home Assistant.
  2. Add the integrationWith HACS: Settings › Devices & Services › Add Integration › “HAGHS”. The Marketplace opens the setup right away.
  3. Follow the setupStorage type, ignore labels and patterns. CPU and RAM sensors are only needed when your host has no PSI. Database size and disk usage are detected automatically.
  4. Add a dashboard cardReady-made Lite and Pro cards show the score, the breakdown and links to the right settings pages.

automations.yaml · example
# Get a notification when the score drops below 80
- alias: "HAGHS: health score dropped"
  triggers:
    - trigger: numeric_state
      entity_id: sensor.system_ha_global_health_score
      below: 80
  actions:
    - action: notify.notify  # or your own notify action
      data:
        title: "Home Assistant health: {{ states('sensor.system_ha_global_health_score') }}"
        message: "{{ state_attr('sensor.system_ha_global_health_score', 'recommendations') }}"
